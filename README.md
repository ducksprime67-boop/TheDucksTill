# TheDucksTill
The Duck Till is a free, open-source desktop POS app for running your shop. There’s is setup or installation—just run the single setup.exe file, install it and you are done :). add your inventory, ring up sales, convert 200+ currencies, and print receipts with zero hassle!


## 🦆 THE DUCK TILL - QUICK START GUIDE


Hey! Thanks for checking out The Duck Till. 

I built this app because I wanted a clean, open-source POS 
and inventory manager that actually gets out of your way instead 
of feeling like clunky, bloated enterprise software. Whether you're 
running a small shop, testing an e-commerce side hustle, or just 
messing around with Python apps, I hope this helps you out!

-------------------------------------------------------------
### 🛠️ HOW TO GET IT RUNNING
-------------------------------------------------------------

1. Make sure Python is installed on your computer.
2. Grab the dependencies if you haven't already (Pillow for images, 
   and tkinterdnd2 if you want drag-and-drop support):

   pip install pillow tkinterdnd2

3. Open up your terminal or command prompt in this folder and run:

   python the_duck_till.py

-------------------------------------------------------------
### 💡 A FEW HELPFUL TIPS
-------------------------------------------------------------
• Top-Right Currency Switcher: I built in 200+ world currencies so 
  you can switch to your local currency anytime without breaking prices.
• Inventory First: Add a few items in the Inventory tab before heading 
  over to the Point of Sale tab to start adding things to your cart.
• Custom Receipts: Go to the "Bill System" tab to put in your store name, 
  address, and tax info so your receipts look official.

-------------------------------------------------------------
### ⌨️ KEYBOARD SHORTCUTS
-------------------------------------------------------------
• Up / Down Arrows : Scroll through your items
• Ctrl + A         : Select everything in a list
• Delete           : Remove selected item(s)
• Esc              : Exit the app
